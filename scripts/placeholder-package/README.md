# cardano402

This package name is a **reservation stub**. The cardano402 project
publishes under the `@cardano402/*` scoped namespace.

Install the package you actually want:

- [`@cardano402/core`](https://www.npmjs.com/package/@cardano402/core) — schemas, types, header codec, and `FacilitatorClient`
- [`@cardano402/mcp-server`](https://www.npmjs.com/package/@cardano402/mcp-server) — MCP server for AI agents that pays for x402-priced HTTP endpoints

Framework adapters (private workspace members; not yet published to npm):

- `@cardano402/axios`, `@cardano402/express`, `@cardano402/fastify`, `@cardano402/fetch`, `@cardano402/hono`, `@cardano402/next`
